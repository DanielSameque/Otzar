# Glossário


| Termo                    | Definição                                                                                       |
| ------------------------ | ----------------------------------------------------------------------------------------------- |
| **Otzar**                | Sistema de gestão de tarefas, projetos e conhecimento.                                          |
| **Tarefa**               | Unidade central de trabalho do Otzar. Pode existir com ou sem projeto.                          |
| **Projeto**              | Agrupamento de informações relacionadas a um produto, sistema ou contrato.                      |
| **Backlog**              | Visualização das tarefas que não possuem uma Sprint associada. Não é uma entidade persistida.   |
| **Sprint**               | Ciclo de desenvolvimento que pode conter tarefas de diferentes projetos.                        |
| **Kanban**               | Visualização das tarefas organizadas por status.                                                |
| **Subtarefa**            | Tarefa vinculada a outra tarefa por meio de uma relação pai/filho.                              |
| **Cliente**              | Pessoa ou organização atendida pela empresa e relacionada a projetos ou tarefas.                |
| **Usuário**              | Pessoa que utiliza o Otzar.                                                                     |
| **Categoria**            | Classificação que representa o tipo de trabalho de uma tarefa.                                  |
| **Tag**                  | Classificação personalizada utilizada para identificar ou agrupar tarefas e documentos.         |
| **Base de Conhecimento** | Conjunto de documentos Markdown associado a um projeto.                                         |
| **Documento**            | Arquivo ou conteúdo Markdown utilizado para registrar conhecimento e documentação.              |
| **Versão**               | Identificação de uma versão ou ciclo de evolução de um projeto ou tarefa.                       |
| **Responsável**          | Usuário designado para executar ou acompanhar uma tarefa.                                       |
| **Status**               | Estado atual de uma tarefa ou outro recurso do sistema.                                         |
| **MVP**                  | Primeira versão funcional do Otzar utilizada para validar o produto, arquitetura e experiência. |
| **Roadmap**              | Planejamento de evolução do produto. Não substitui o Backlog.                                   |
